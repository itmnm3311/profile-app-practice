# profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
Laravelを使用して、プロフィール情報を表示するWebページを作成しました。
名前・年齢・趣味をコントローラーで管理し、ビューに渡して表示しています。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Blade テンプレート

## 学んだこと
- コントローラーの作成とルーティングの設定
- コントローラーからビューへのデータの受け渡し
- compact() を使った変数の受け渡し

## 動作確認
http://localhost/profile にアクセス
